用置換檢定估計 RT 實驗的樣本數

每位受試者做幾個 trial，會決定你需要幾位受試者。拉動下面的滑桿，看雜訊怎麼縮小，以及人數為什麼最後降不下去。

本文用 flanker 或 Stroop 類型的反應時間（RT）實驗當例子，示範怎麼用模擬加置換檢定估計所需的受試者人數，並說明每人的 trial 數為什麼會左右結果。

文中所有參數（RT 分布、效果大小、受試者間變異）都是我假設的，沒有一項是從真實資料估計的。拿去規劃自己的實驗時，請換成 pilot 資料或文獻中的估計值，並至少加跑一組比預期更小的效果。

決策規則和效果，要分開處理

置換檢定沒有現成的 power 公式。它對手上的資料重新分配標籤或正負號來建立虛無分布，這個步驟本身不會產生「真的有效果」的資料。所以估計 power 要拆成兩件事：置換檢定提供決策規則，決定一份資料算不算顯著；效果則由你假設的資料生成模型提供。對資料做置換會把效果洗掉，因此不能用置換造出 H1 的資料。

把兩者接起來，重複很多次，顯著的比例就是 power。

  1. 資料生成：你的假設假設真實效果平均 δ，受試者間標準差 σb
  2. 資料生成：你的假設模擬 trial每人兩個條件各產生 n 個 RT
  3. 決策規則：置換檢定每人壓成一個差值不一致的平均減一致的平均，得到 di
  4. 決策規則：置換檢定符號翻轉置換重複 B 次建立虛無分布，算出 p 值
  5. 重複重複 S 次顯著的比例就是 power。換一個 N 再做一輪
資料生成：你的假設決策規則：置換檢定重複

資料生成模型

每位受試者在兩個條件（一致、不一致）各有 n 個 trial。基準 RT 對兩個條件相同，相減時抵消，不影響 power；真實資料中基準較慢的人常有較大的效果，這個相關這裡沒有模擬。受試者 i 的真實效果 θi 服從平均 δ、標準差 σb 的常態分布。

分析時每人只保留一個數字：

di = 不一致條件的平均 RT − 一致條件的平均 RT對每位受試者 i

平均了 n 個 trial 之後，di 近似常態，可以寫成「真實效果」加上「估計誤差」：

di ≈ θi + εi， Var(εi) = 2σ2tn

置換檢定做了什麼

配對設計的虛無假設是：差值 di 的分布對 0 對稱。成立的話，把某位受試者的差值換成相反的正負號，資料的機率不變。所以做法是保留每個 |di|，隨機決定每人的正負號，重算組平均，重複 B 次，得到「虛無假設成立時，組平均會長什麼樣」的分布。

p 值是這個分布中絕對值不小於觀察值的比例，分子分母各加 1，避免 p = 0。

掃描 N，得到 power

固定每人每條件 40 個 trial，對每個候選的 N 各跑 1000 次模擬實驗，真實平均效果取 25 ms 和 15 ms。

為什麼 trial 數會影響 power

置換檢定只看到每位受試者的一個差值 di，不知道背後有幾個 trial。trial 數是透過 di 的雜訊間接影響 power。由上面的模型，di 的變異分成兩項：

Var(di) = σ2b + 2σ2tn

藍色那項是人與人之間真實的差異，不隨 n 改變；朱紅色那項是 trial 雜訊，隨 n 增加而縮小。頁首的互動畫的就是這兩項。n 小的時候朱紅色占大部分，多收 trial 能大幅縮小總變異；n 夠大之後只剩藍色，dz 逼近上限 δ / σb，再多的 trial 也越不過去。

以 δ = 15 ms 為例，每人每條件 10 個 trial 需要約 72 位受試者，40 個 trial 需要 30 位，160 個 trial 需要 20 位，即使 trial 數無限多也還需要 16 位。δ = 25 ms 時對應的人數是 28、13、9 和 8。

規劃時可以先決定受試者人數和每人 trial 數的組合，再對照這張表看 power 夠不夠。招募受試者比較貴的話，增加 trial 可以省人，但省下的人數有下限，兩種效果量的下限分別是 16 位和 8 位。這張表來自解析近似，正式採用前，建議用原始檔裡的 power() 在你要用的組合上實際模擬一次。

實際使用時

  1. 換成自己的資料生成模型。有 pilot 資料的話，可以對受試者做 bootstrap，取代參數式生成，再和這裡的結果比較。兩者差距大，代表假設的分布形狀有問題。bootstrap 無法外推到比 pilot 更大的 N。
  2. 換成自己要用的統計量。正式分析用的若是中位數差、trimmed mean 或最大統計量校正，只需要改 perm_p 裡的統計量，其餘流程不變。這是模擬法相對於解析公式的主要好處。
  3. 效果量跑一個範圍。pilot 的效果量通常偏高，建議至少再跑一組縮小後的值（例如 pilot 估計的一半到三分之二），報告 N 的範圍。
  4. 留意 Monte Carlo 誤差。power 約 0.8 時，S = 1000 的標準誤差約 0.013；相鄰兩個 N 的差距若小於這個量級，不要過度解讀。
  5. 檢查 B。置換 p 值的最小值是 1/(B+1)。改用更嚴格的 α（例如多重比較校正後）時，B 要跟著增加。

限制

  • 所有結論以假設的模型為條件：trial 彼此獨立、效果在受試者間近似常態、基準 RT 與效果量無相關。真實 RT 資料常有練習效果、疲勞和序列相依，這些會讓 trial 雜訊不再以 1/n 的速度縮小。
  • σb = 20 ms 是假設。受試者間變異越小，增加 trial 的效益持續得越久；越大，上限來得越早。
  • 這裡的置換單位是受試者（符號翻轉受試者層級的差值）。如果正式分析是 trial 層級（例如混合效果模型，或在受試者內置換條件標籤），可交換單位和模擬方式都要重新設計，本文的結果不能直接套用。
  • 解析近似只是檢查工具。受試者數很少、差值明顯偏態或有離群值時，置換檢定與 t 檢定的 power 會出現差異，應以模擬結果為準。
