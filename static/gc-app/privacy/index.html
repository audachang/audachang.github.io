Privacy Policy

Effective date: 23 September 2026

This policy explains how gc-app ("the app"), operated by Erik Chihhung Chang ("the operator"), handles data from Google accounts that authorize it. The app is a private integration used only by the operator and the Google accounts he administers.

1. Data the app accesses

With the account owner's consent, the app may request the following Google OAuth scopes. The account owner can grant a subset on the consent screen, and the app only uses what was granted.

ScopePurpose
calendarRead events; create, update, or delete events on request.
gmail.readonly, gmail.modifySearch and read messages; apply or remove labels.
gmail.sendSend or reply to email when the account owner asks.
drive.readonly, documents.readonlySearch and read files and documents.
spreadsheetsRead and update spreadsheets the account owner identifies.
contacts.readonlyLook up contact details.

2. How the data is used

Google user data is used only to carry out tasks the account owner explicitly requests from the assistant, or scheduled tasks the account owner has set up (for example, a daily agenda summary). The app does not use Google user data for advertising, profiling, or any purpose unrelated to these user-facing features.

3. Storage and security

  • OAuth access and refresh tokens are stored in a file readable only by the service account on a private, access-controlled server operated by the operator. Access to the server requires SSH key authentication.
  • Content retrieved from Google (for example, an event title or email text) is processed in memory to answer a request. Conversation logs kept by the assistant may contain excerpts of that content; these logs stay on the same private server.
  • All communication with Google APIs uses HTTPS.

4. Sharing and third parties

The app does not sell, rent, or trade Google user data. To answer a request, relevant excerpts may be sent to the large language model API provider configured for the assistant, solely to generate the response to that request. Google user data is not otherwise shared, except when required by law.

5. Limited Use disclosure

gc-app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app does not use Google Workspace API data to develop, improve, or train generalized AI or machine learning models.

6. Retention and deletion

Tokens are kept until the account owner revokes access. The account owner can revoke access at any time at myaccount.google.com/permissions; the stored token then stops working and is deleted by the operator. To request deletion of any retained logs, email the operator at the address below. Requests are handled within 30 days.

7. Changes

Updates to this policy are posted on this page with a new effective date.
