Dataset overview

115-0004.zip (572 MB; about 2.5 GB uncompressed) holds one folder, 115-0004/, with 179 CSV files of institutional data exported from National Central University (NCU). The files fall into four groups. All are UTF-8 with a BOM, comma-separated, with column names in the first row. Student IDs and teacher national ID numbers have been replaced with 64-character hexadecimal hashes. Column names below are kept in the original Chinese, as they appear in the files, followed by an English gloss.

In the enrollment file names, YYYS is the ROC academic year plus semester (1092 = academic year 109, spring semester, i.e. spring 2021), and (NN) is a part number from splitting by row count. Parts per semester: 10 each for 1041, 1061, 1062, 1071, 1081, 1091, 1112, 1122, 1131 and 1132; 13 for 1101; 9 each for the other seven semesters. There are no enrollment files for 1111 (fall 2022) or 1121 (fall 2023), although the course-offerings file covers both. The two publication files carry request number 115-0005 but are packed inside the 115-0004 archive.

Scope of this review: all 179 file names, plus the six files actually opened (course offerings, both publication files, and enrollment parts 1092(01), 1122(02) and 1132(10)). Value ranges and proportions for the enrollment data come from those three parts only and do not represent whole semesters. The package contains no official codebook; meanings below are inferred from column names and observed values, and items marked "inferred" should be confirmed with the data provider.

Course-enrollment allocation history (14 columns)

Each row is one student's request for one course in one allocation round, so the same student–course pair can appear in several rows across rounds (in part 1122(02), 31,454 rows repeat a student–course pair). Parts appear to be ordered by allocation round: 1092(01) contains only round codes 574 and 575, and 1132(10) only 728, so outcome distributions in any single part are skewed toward particular rounds.

Course offerings (52 columns)

Each row is one course section in one semester, covering 24 semesters from 103-1 to 114-2, about 2,060–2,380 sections per semester. Twenty rows are shifted because quotation marks and file paths inside text fields break the CSV structure; they can be dropped by keeping rows where 開課學校名稱 equals 國立中央大學, leaving 53,177 rows. The value ranges below are after that filter.

Journal articles (21 columns) and conference papers (28 columns)

In both files each row is "one NCU faculty member × one publication", so a paper with several NCU authors appears in several rows: 4,901 of the 17,514 journal rows repeat an earlier title. The journal file covers 957 faculty members and the conference file 597, with 503 in both. Columns shared by both files are listed first.

Join keys and data-quality notes

Enrollment and course offerings join directly. The publication files can only be related to teaching data at the unit level, and that requires building a unit-code crosswalk.

Join Key Match rate or limitation
Enrollment → course offerings 學期別 = 學年學期 and 課號 = 課程流水號 98.4–99.8% in the three sample parts
Enrollment across semesters 學號 (hash) Hash is consistent across semesters, allowing student-level longitudinal tracking
Student department → offering unit 4-digit department code Same scheme, so home-department and outside courses can be distinguished
Journal ↔ conference 教師身份證字號 (hash) 503 faculty members appear in both
Publications ↔ course offerings No shared faculty key Hashes on one side, names on the other; unit codes also use two schemes (T/R codes vs. 4 digits), so a crosswalk must be built from unit names

Issues to handle before analysis:

  • Enrollment data are missing semesters 1111 and 1121, leaving gaps in longitudinal analyses.
  • 學生所屬系所代碼 is entirely blank in part 1092(01); other semesters have not been checked. It can be back-filled from the department name.
  • The same student–course pair can appear across several allocation rounds; to get the final enrollment state, take the latest round per pair. The data contain no drops or grades.
  • Twenty course-offering rows are misaligned; filter on 開課學校名稱 after loading.
  • Course offerings have no credits column, and 授課教師 contains plain-text names that should be de-identified before any sharing or export.
  • Text fields contain HTML tags, line breaks and several missing-value spellings (無, N/A, TBA, None, -) that need to be unified.
  • 41 publication rows have author position > author count; publication counts should be de-duplicated by title first.
  • Whether the hashes are salted, how 籤號 relates to priority, and the official definitions of the outcome categories all need confirmation from the data provider.
This page describes column structure and aggregate statistics only; it contains no row-level data about any student or faculty member. Most meanings are inferred from column names and values; the data provider's definitions take precedence.
