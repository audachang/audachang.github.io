行動的空間地圖：PPC The Spatial Map for Action

後頂葉皮質 Posterior Parietal Cortex (PPC) 是 cross-modal integration 的樞紐：

  • 視覺：杯子的位置
  • 本體感覺 proprioception：手臂與手的位置
  • 觸覺 tactile feedback：來自指尖的回饋

PPC：以行動為中心的表徵 Action-centered Representation

  • 編碼「可能的動作」，而不只是物體的靜態位置
  • 一個位於 (30, 50, −7) 的杯子 ✗
  • 一個「可以被抓起來」的杯子 ✓
  • 把視覺場景轉成一張「動作可能性」的地圖
    • → affordances（環境提供給行動者的動作機會）

行動的計畫（一）：Premotor Cortex PMC

前運動皮質 Premotor Cortex (PMC)

  • 使用 PPC 提供的空間地圖，準備特定的動作
  • 建立身體與肩膀的正確 postural set（姿勢設定）

行動的計畫（二）：Supplementary Motor Area SMA

輔助運動區 Supplementary Motor Area (SMA)

  • 計畫與組織複雜、熟練、bimanual（雙手）的動作序列
  • Selection of action sequences：選擇要執行的動作序列
  • Coordinating bilateral effectors：協調左右兩側的動作器
  • 在 mental rehearsal（心中預演）時也會活化，不只在實際執行時

動作的複雜度與參與的皮質區 Complexity of Actions

簡單動作（simple）→ 複雜動作（complex）→ 只「想像」複雜動作（imagined）：比較 M1/S1 與 SMA 的活化

植物人狀態下的動作想像 Motor Imagery in the Vegetative State

想像打網球（tennis imagery）→ SMA；想像在空間中走動（spatial navigation imagery）→ PMC、PPC、PPA。病人（上）與控制組（下）的活化模式相似。

動作執行：Primary Motor Cortex M1

初級運動皮質 M1：動作的「發射台」motor launch pad

  • 把 PMC 與 SMA 的抽象計畫，轉成具體的 motor commands
    • 力量 force
    • 方向 direction

M1：族群編碼與即時修正

  • Population coding
    • 最終的動作方向，由一大群神經元加權後的整體活動決定
  • Real-time correction
    • 透過 long-loop reflexes 接收感覺回饋
    • 對突發事件快速調整，例如杯子快要滑掉

動作神經系統的階層 Hierarchy in the Motor Neural System

  • Descending systems（上運動神經元）
    • Motor cortex：計畫、啟動與引導隨意動作
    • Brainstem centers：基本動作與姿勢控制
  • 調控迴路
    • Basal ganglia：動作啟動的「閘門」
    • Cerebellum：進行中動作的感覺–動作協調
  • Spinal cord & brainstem circuits
    • Local circuit neurons → motor neuron pools → 骨骼肌

為何運動對大腦有益？（一）短期 Short-term

平衡神經傳導物質 Balancing neurotransmitters

  • 正腎上腺素 Norepinephrine → 注意力控制 attentional control
  • 血清素 Serotonin → 情緒調節 emotional regulation
  • 多巴胺 Dopamine → 連結獎賞與學習

為何運動對大腦有益？（二）長期 Long-term

增加神經滋養因子的生成，促進可塑性 Neurotrophins

  • 腦衍生神經滋養因子 BDNF → 形成神經元與突觸
  • 第一型類胰島素生長因子 IGF-1 → 促進 BDNF
  • 血管內皮生長因子 VEGF → 形成新的微血管
  • 纖維母細胞生長因子 FGF-2 → 強化新生的神經元

BDNF 屬於 neurotrophin 家族。運動會增加 BDNF 的分泌；肌肉收縮也會分泌 BDNF，參與肌肉修復與再生。
