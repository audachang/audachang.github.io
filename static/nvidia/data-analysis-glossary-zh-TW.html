1-02 · 資料操作

fundamentals/1-02_data_manipulation.ipynb
cuDF
RAPIDS 的 GPU DataFrame 函式庫。本筆記本以類似 pandas 的介面，在駐留 GPU 的資料上進行載入、選取、篩選、分組與建立欄位等操作。
DataFrame 索引（index）
辨識每一列的標籤。筆記本以 .loc 依標籤選取，而非依數值位置選取；在排序、篩選或串接資料後，兩者的差異尤其重要。
布林遮罩（Boolean mask）
與資料列等長、由 True／False 組成的序列，用來保留符合條件的列，例如位於 Sunderland 以北的郡。它是向量化篩選的基礎。
UDF（使用者自訂函式）
由使用者定義的函式。.map() 逐元素套用；.apply() 可沿列或欄運作。兩者很方便，但通常不如內建的向量化操作有效率。

1-03 · 記憶體管理

fundamentals/1-03_memory_management.ipynb
記憶體額外負擔（memory overhead）
DataFrame 邏輯資料值以外所需的記憶體。本筆記本中，GPU 使用量可能高於 DataFrame 回報的大小，因為 CSV 剖析與載入的中間步驟會配置額外緩衝區；執行時應預留這類尖峰所需空間。
memory_usage(deep=True)
pandas 用來估計物件字串欄位實際記憶體的選項。若未設定 deep=True，可能只計算指標而低估字串內容本身的儲存量。
降階轉型（downcasting）
把數值改為較小但仍相容的型別，例如 int64 改為 int8 或 float64 改為 float32。可減少儲存量與記憶體傳輸，但前提是數值範圍與所需精度仍能保留。
類別型資料（categorical data）
將重複出現的離散標籤存成類別字典與整數代碼。對低基數的文字欄位可節省記憶體並加速操作，也能保留有意義的排序。

1-04 · GPU PyData 互通性

fundamentals/1-04_interoperability.ipynb
CuPy
與 NumPy 相容的 GPU 陣列函式庫。筆記本以它處理數值陣列，可與 cuDF DataFrame 並用，避免不必要地把資料傳回 CPU 的 NumPy。
英國國家格網／OSGB
英國使用的投影座標參考系統。經緯度轉換後的 easting 與 northing 以公尺為單位，因此在局部距離分析時，比直接以角度單位的經緯度計算更合適。
向量化（vectorization）
一次對整個陣列運算，而不是用 Python 逐筆迴圈。格網座標轉換器中的 NumPy／CuPy 表達式能呈現足夠的平行工作，讓函式庫有效使用 CPU 或 GPU。
布林陣列索引
以布林陣列選取陣列中的值。它相當於 DataFrame 的布林遮罩，可用於保留符合計算條件的元素。

1-05 · 分組

fundamentals/1-05_grouping.ipynb
分割—套用—合併
groupby 的思考方式：先依鍵值分割資料，再在各群內套用彙整或轉換，最後合併結果。例如依郡計算平均年齡。
分箱（binning）
把連續數值變數切為區間，例如年齡層。它讓摘要與作圖較簡單，但會犧牲箱內的細節；箱界位置會影響看到的模式。
transform 與 apply
transform 的輸出會與原始列對齊，例如為每個人附上其群組平均值；apply 較有彈性，可能回傳縮減或改變形狀的結果。
樞紐分析表（pivot table）
把群組安排成列與欄，並以彙整值填入儲存格的交叉摘要表。它能精簡地檢視兩個類別維度之間的關係。

1-06 · 資料視覺化

fundamentals/1-06_data_visualization.ipynb
直方圖（histogram）
顯示落在各數值區間內觀測值數量的圖。它不同於具名類別的長條圖；連續分布呈現出的形狀會隨箱寬改變。
Datashader
面對大量點資料的繪圖方法：先把資料彙整到螢幕像素，再進行渲染。這可避免點位重疊，也讓逐列繪製會過慢或不清楚的圖仍可閱讀。
cuxfilter 儀表板
以 GPU 為導向的互動式視覺化儀表板，可連動多個視圖。在一個視圖篩選或選取後，其他視圖會同步更新，適合探索大型資料。

1-07 · 擷取、轉換、載入

fundamentals/1-07_etl.ipynb
ETL
Extract、Transform、Load 的縮寫：從來源取得資料、清理／重新編碼／衍生分析用欄位，再寫入目標系統或檔案。筆記本將前處理視為可重現的流程，而非一次性的手動工作。
Parquet
二進位欄式檔案格式。它依欄儲存資料並保留中介資料與壓縮資訊，分析讀取時可只載入需要的欄位，通常比反覆剖析 CSV 更有效率。
欄式儲存（columnar storage）
依欄位而非依資料列排列的實體儲存方式。它適合分析性的掃描與彙整，也利於壓縮，因為同一欄的值相鄰且往往相似。

1-08 · cuDF Polars

fundamentals/1-08_cudf-polars.ipynb
立即執行（eager execution）
每個操作立即執行並回傳結果。它適合互動式使用，但在後續操作尚未得知前，就已決定了執行方式。
延遲執行（lazy execution）
先建立查詢計畫，待呼叫 collect() 才執行。Polars 因而能對整個計畫最佳化，例如提早篩選或避開未使用欄位。
執行圖（execution graph）
呈現資料操作與相依關係的有向圖。檢視它可理解延遲模式如何在不改變要求結果的前提下，合併或重排工作。

1-09 · Dask cuDF

fundamentals/1-09_dask-cudf.ipynb
分區（partition）
分散式 DataFrame 的一個資料區塊。Dask 將超過單張 GPU 容量的資料切成分區，交由工作節點平行處理；分區大小會影響排程額外負擔與記憶體壓力。
Dask 排程器（scheduler）
將任務圖轉成工作指派、遵守相依關係並分配給工作節點的協調者。它負責編排計算，本身不是執行 DataFrame 計算的位置。
LocalCUDACluster
在本機啟動 GPU 感知工作節點的 Dask 叢集設定，通常每張可見 GPU 對應一個工作節點，使 Dask cuDF 工作可跨 GPU 分配。
persist()
把延遲的 Dask 集合具體化並留在工作節點記憶體中，同時維持其分散式集合身分。適合重複使用的中間結果，但需計入它占用的叢集記憶體。

2-02 · 準備圖形建構資料

fundamentals/2-02_prep_graph.ipynb
圖、頂點、邊
圖以頂點（節點）表示實體，以邊表示關係。此處道路交叉點是頂點、道路路段是邊；分析前必須確認邊端點 ID 能與頂點 ID 正確對應。
邊權重（edge weight）
附在邊上的數值成本。筆記本依道路長度與道路類型的速度假設換算行車秒數，因此「最短」可以指最快，而非物理距離最短。
節點重新編號（reindexing）
把外部節點識別碼替換為緊湊、連續的 ID 範圍。這可使圖形建構與 GPU 演算法更有效率，但必須保留對照表以解讀結果。

2-03 · cuGraph 單一來源最短路徑

fundamentals/2-03_cugraph.ipynb
單一來源最短路徑（SSSP）
從一個指定來源頂點，計算到所有可達頂點的最小總邊權重。若權重是時間，本筆記本即估計穿越道路網的行車時間。
可達性（reachability）
在圖的連通與方向規則下，兩個頂點之間是否存在路徑。不可達頂點沒有從來源出發的有限路徑，不能只解讀成「非常遠」。

2-04 · cuGraph 作為 NetworkX 後端

fundamentals/2-04_networkx_cugraph.ipynb
後端分派（backend dispatch）
讓相容的 NetworkX 風格呼叫透過加速的 nx-cugraph 後端執行的機制。程式碼可維持熟悉的介面，但底層計算實作已改變。
中心性（centrality）
衡量頂點在網路結構中重要性的指標家族。它不是籠統的「重要性」事實：不同指標對應不同的網路角色，應依實質問題選擇。
中介／度數／特徵向量／PageRank／Katz 中心性
中介中心性計算經過節點的路徑；度數中心性計算直接連結數；特徵向量與 PageRank 會提高連到重要節點的分數；Katz 也計入較長的路徑，但會折減其貢獻。這些意義不能互換。

3-02 · K-Means

fundamentals/3-02_k-means.ipynb
K-means 分群
一種非監督式方法，將每筆觀測值分配到預先指定數量 k 的群組，並反覆更新群中心，以減少群內的平方距離。
質心（centroid）
K-means 群組中所有點的平均位置。它是數學上的中心，不必是某位實際的人或某個實際地點，且會受尺度與離群值影響。
特徵縮放（feature scaling）
在以距離為基礎的學習前，將輸入變數放到可比較的數值尺度。否則數值範圍較大的特徵，可能不論其實質重要性而主導 K-means 的距離。

3-03 · DBSCAN

fundamentals/3-03_dbscan.ipynb
DBSCAN
Density-Based Spatial Clustering of Applications with Noise 的縮寫。它從密集點群形成叢集，可找出非球形結構，並把不在高密度區域內的點標為雜訊。
eps 與 min_samples
eps 是鄰域半徑；min_samples 是一個點成為核心點所需的鄰近點數。兩者共同定義何種密度算成叢集，尺度必須與特徵單位相符。
雜訊標籤（noise label）
DBSCAN 指派給未與任何叢集形成密度連通關係之觀測值的標籤，通常是 -1。這是演算法結果，不代表該量測一定錯誤。

3-04 · Logistic Regression

fundamentals/3-04_logistic_regression.ipynb
邏輯斯迴歸（logistic regression）
以年齡、性別等預測變數，建立二元結果（本例為感染）機率的監督式分類模型。它將線性分數以 logistic 函數轉換到 0 至 1 的機率尺度。
係數與勝算（odds）
係數改變的是模型的對數勝算，而不是以固定幅度改變機率。係數取指數後是勝算比，但仍要連同模型設定與其他預測變數解讀。
訓練／測試切分
保留一部分未用於配適的資料，之後以它評估訓練好的模型。這可估計對相似但未見資料的泛化表現，避免把樣本內表現誤當成預測能力。
盛行率（prevalence）
在特定族群或子群中具有該結果者的比例。依年齡或性別觀察到較高盛行率，是描述性的結果，本身不能證明因果風險因子。

3-05 · K-Nearest Neighbors

fundamentals/3-05_knn.ipynb
K 最近鄰（KNN）
針對每個查詢點，找出參考資料中 k 個距離最近點的距離式方法。本筆記本用它把醫院對應到附近道路節點；它不會學習道路網路本身的模型。
查詢資料與參考資料
參考資料先建立索引供搜尋；查詢資料則拿來查找鄰居。解讀回傳的距離與鄰居索引時，必須分清兩者角色及各自的列索引。
歐幾里得距離
在提供的特徵空間中的直線距離。投影為以公尺計的格網座標後很有用，但它不是道路行車距離，也可能忽略障礙或網路限制。

3-06 · XGBoost

fundamentals/3-06_xgboost.ipynb
XGBoost／梯度提升
一種循序建立決策樹的集成方法；每棵新樹用來修正先前集成的錯誤。它適合表格資料預測，但仍須驗證與審慎設定參數，以避免過度配適。
超參數（hyperparameter）
在訓練前或訓練過程中設定、而非直接由訓練樣本學得的值，例如樹深、學習率或提升回合數。應使用驗證資料調整，不能用最終測試集調參。
特徵重要性（feature importance）
由模型推得、概括各預測變數對分裂或損失降低貢獻的摘要。它可供檢視，但不能證明因果，亦可能受相關特徵或所採重要性定義影響。
ROC AUC
受試者操作特徵曲線下面積：隨機抽一個正例與一個負例時，模型將正例評分較高的機率。它衡量跨閾值的排序辨識力，不單獨衡量校準度或實務效益。

3-07 · Triton

fundamentals/3-07_triton.ipynb
推論伺服器（inference server）
接收模型輸入並回傳預測結果的服務。Triton 將訓練完成的模型包裝成可提供服務的形式、處理請求並支援多種後端；這不同於模型訓練。
模型儲存庫與設定檔
Triton 要求依模型名稱與版本整理目錄，並提供 config.pbtxt。設定檔宣告輸入、輸出、批次上限與後端設定等部署層面的資訊。
批次大小與併發數
批次大小是每個請求包含的輸入數；併發數是同時尚未完成的請求數。提高任一項可能改善 GPU 使用率與吞吐量，但也可能增加延遲或超出記憶體限制。
延遲、吞吐量、p50／p95／p99
延遲是每個請求花費的時間；吞吐量是單位時間完成的推論數。百分位數概括延遲分布，例如 p95 表示 95% 的量測請求在該值或更短時間內完成。

3-08 · 以 Dask 進行多 GPU K-Means

fundamentals/3-08_k-means_dask.ipynb
多 GPU 訓練
將資料分區並協調計算，讓一項分析跨多張 GPU 執行。它可擴充容量與速度，但效益取決於分區平衡、通訊成本，以及工作量是否足以抵銷額外負擔。
分散式 K-means
在 Dask 管理的分區上執行 K-means。各工作節點的本地計算會共同更新全域質心，因此它結合平行本地工作與跨叢集同步。

4-02 · 找出感染者叢集

fundamentals/4-02_find_infected.ipynb
空間叢集（spatial cluster）
地理位置集中的病例群。在本專題中，DBSCAN 以投影格網座標辨識高密度模式；找到叢集表示值得進一步調查的模式，不是感染原因的解釋。
最大叢集（largest cluster）
被指派至該叢集的觀測值數量最多的叢集。它不同於地理面積最大或局部密度最高的叢集，因此應清楚說明判準。

4-03 · 找出最近醫療設施

fundamentals/4-03_nearest_facilities.ipynb
Easting 與 northing
投影格網的水平與垂直座標。在此使用的英國國家格網轉換中，兩者以公尺為尺度，因此 KNN 可計算具有明確意義的直線鄰近程度。
最近設施索引
kneighbors 回傳的整數，用來指出設施參考 DataFrame 中距離最近的那一列。必須以它連回 OrganisationID 等設施中介資料；重設索引可避免列標籤錯配。

4-04 · 找出感染風險因子

fundamentals/4-04_identify_risk_factors.ipynb
分層（stratification）
在子群中計算摘要，例如同時依就業代碼與性別計算。這可檢視整體模式是否在重要分組中一致，也可能發現整體比例掩蓋的差異。
風險因子（risk factor）
在特定分析中，與較高結果率有關的特徵。專題中的分組感染率可指出值得後續研究的候選因素；觀察到的關聯本身不能證明就業或性別造成感染。
