Fundamentals of Accelerated Data Science

How to read this stack 如何閱讀這個堆疊：

The NVIDIA accelerated computing stack is a series of layers trading ease of use against control and performance. The top layers require zero or minimal code changes but hide the GPU details; the bottom layers require writing C++/CUDA but offer maximum performance. Most data science work happens in the top three layers.

NVIDIA 加速運算堆疊由多個層級組成，在「易用性」與「控制度／效能」之間取捨：越上層越不需要改動程式碼（但對 GPU 細節的控制越少）；越下層越需要撰寫 C++/CUDA（但效能上限越高）。大多數資料科學工作只會用到最上面三層。

Foundations 基礎概念

(terms behind the whole stack 貫穿整個堆疊的核心名詞)
These terms appear in every layer below — make sure they are solid first. 以下名詞會在所有層級反覆出現，建議先確實掌握。
Term 術語Full name 全名Definition (English)說明（繁體中文）
GPU Graphics Processing Unit A processor with thousands of small cores designed for massively parallel computation. Originally built for graphics, now the workhorse of accelerated data science and AI. 圖形處理器。具備數千個小型運算核心，專為大規模平行運算設計；原為繪圖而生，現已成為加速資料科學與 AI 的主力硬體。
CPU Central Processing Unit A processor with few but powerful cores, optimized for sequential and general-purpose tasks. In accelerated computing, the CPU orchestrates work and the GPU executes the parallel parts. 中央處理器。核心數少但單核效能強，擅長循序與通用工作。在加速運算中，CPU 負責調度流程，GPU 負責平行運算的部分。
API Application Programming Interface A defined interface through which software components communicate. It specifies the functions, inputs, outputs and rules a library or service exposes, so a program can use it without knowing its internal implementation. 應用程式介面。一組讓軟體元件彼此溝通的明確規格，定義函式庫或服務提供的功能、輸入、輸出與使用規則；程式可據此使用功能，而不必知道內部如何實作。
CUDA Compute Unified Device Architecture (original expansion; now used simply as a name 原始全名，現多直接作為名稱使用) NVIDIA's parallel computing platform and programming model — the foundation every library in this stack is built on. It lets programs define work that runs across thousands of GPU threads. NVIDIA 的平行運算平台與程式設計模型，是本堆疊中所有函式庫的共同基石；讓程式能定義由數千條 GPU 執行緒平行執行的工作。
kernel — (general CUDA concept 通用概念) A function that runs on the GPU, executed simultaneously by many threads. "Writing a kernel" means writing the code each GPU thread will run. 核心函式：在 GPU 上執行的函式，由大量執行緒同時執行同一段程式碼。「撰寫 kernel」即撰寫每條 GPU 執行緒要跑的程式。
RAPIDS — (brand name, not an acronym 品牌名稱，非縮寫) NVIDIA's open-source suite of GPU-accelerated data science libraries (cuDF, cuML, cuGraph, cuVS, RMM…). Its APIs deliberately mirror pandas, scikit-learn and NetworkX to minimize the learning curve. NVIDIA 開源的 GPU 加速資料科學函式庫套件（含 cuDF、cuML、cuGraph、cuVS、RMM 等）。API 刻意模仿 pandas、scikit-learn 與 NetworkX，以降低學習成本。

1 · Zero Code Change: Acceleration Plugins 零程式碼修改：加速外掛

(no-code change)
Load a plugin or switch a backend and existing pandas / NetworkX / Spark / scikit-learn code runs on the GPU. Unsupported operations automatically fall back to the CPU. Easiest entry point, least control. 完全不改程式碼——只需載入外掛或切換後端，既有的 pandas／NetworkX／Spark／scikit-learn 程式即可在 GPU 上執行；不支援的操作會自動回退（fallback）到 CPU。最容易上手，控制度最低。
Term 術語Full name 全名Definition (English)說明（繁體中文）
cudf.pandas cuDF pandas accelerator mode cuDF's zero-code-change mode. Enabled with %load_ext cudf.pandas (Jupyter) or python -m cudf.pandas, it intercepts pandas API calls, runs supported operations on the GPU, and silently falls back to CPU pandas for the rest. cuDF 的 pandas 加速模式。在 Jupyter 以 %load_ext cudf.pandas（或命令列 python -m cudf.pandas）啟用後，會攔截 pandas API 呼叫，支援的操作在 GPU 上執行，其餘自動回退至 CPU 版 pandas。
nx-cugraph Accelerated NetworkX (cuGraph backend for NetworkX) A GPU backend plugin for NetworkX, the most popular Python graph-analysis library. Once installed, algorithms such as PageRank and shortest paths dispatch to cuGraph on the GPU with no code changes. NetworkX（最普及的 Python 圖分析函式庫）的 GPU 後端外掛。安裝後，PageRank、最短路徑等演算法會自動改由 GPU 上的 cuGraph 執行，程式碼完全不需修改。
RAPIDS Spark Accelerator RAPIDS Accelerator for Apache Spark A plugin for Apache Spark that transparently moves Spark SQL and DataFrame operations onto GPUs, accelerating large-scale ETL and query workloads without changing Spark application code. Apache Spark 的外掛，將 Spark SQL 與 DataFrame 運算透明地轉移到 GPU 執行，加速大規模 ETL 與查詢工作，Spark 應用程式本身不需改寫。
Array-API backed scikit-learn scikit-learn with Python Array API standard support Scikit-learn estimators that support the Array API standard can accept GPU arrays (e.g., CuPy arrays or PyTorch tensors) directly, so the same estimator code computes on the GPU with essentially no changes. scikit-learn 支援 Python「Array API」標準後，部分估計器（estimator）可直接接受 GPU 陣列（如 CuPy 陣列、PyTorch 張量）作為輸入，讓相同的程式碼在 GPU 上運算，幾乎不需改寫。

2 · Hybrid CPU/GPU Libraries 混合 CPU/GPU 函式庫

(minimal change)
One API that runs on either CPU or GPU — usually just a device flag away (e.g., device="cuda"). Develop anywhere, accelerate when a GPU is present. 同一套 API 可在 CPU 或 GPU 上執行，通常只需極少修改（例如指定 device="cuda"）。可先在無 GPU 環境開發，有 GPU 時再加速。
Term 術語Full name 全名Definition (English)說明（繁體中文）
PyTorch — (name 名稱) Meta's deep learning framework built on tensor computation and automatic differentiation. Moving work to the GPU is one call: .to("cuda"). Meta 開發的深度學習框架，以張量（tensor）運算與自動微分為核心；只需 .to("cuda") 一行即可將運算移到 GPU。
FAISS Facebook AI Similarity Search A library for efficient similarity search and clustering of dense vectors, with both CPU and GPU indexes. Widely used in recommender systems and retrieval-augmented generation (RAG). 高效率的稠密向量相似度搜尋與分群函式庫，提供 CPU 與 GPU 兩種索引；廣泛用於推薦系統與檢索增強生成（RAG）。
TensorFlow — (name 名稱) Google's end-to-end machine learning framework. It automatically places operations on a GPU when one is available. Google 開發的端到端機器學習框架；偵測到可用的 GPU 時會自動將運算配置到 GPU 上。
XGBoost eXtreme Gradient Boosting The leading gradient-boosted decision tree library for tabular data. GPU training is enabled with a single parameter (device="cuda"). 梯度提升決策樹（gradient-boosted decision trees）函式庫，表格資料建模的主力工具；只需設定 device="cuda" 即可改用 GPU 訓練。
cuML-CPU cuML CPU execution mode cuML's CPU execution capability: the same cuML estimator code can run on machines without a GPU (e.g., a laptop) and later run unchanged, accelerated, on a GPU system. cuML 的 CPU 執行模式：同一份 cuML 程式碼可先在無 GPU 的環境（如筆電）開發與執行，之後不需修改即可移到 GPU 系統上加速。
Dask — (name 名稱) A Python framework for parallel and distributed computing. It partitions pandas/NumPy/cuDF workloads and schedules them across cores or cluster nodes; combined with RAPIDS (dask-cudf) it scales to multiple GPUs. Python 的平行／分散式運算框架，可將 pandas／NumPy／cuDF 的工作切分並排程到多核心或叢集節點；與 RAPIDS 結合（dask-cudf）即可擴展到多 GPU。
PySpark Python API for Apache Spark The Python interface to Apache Spark, the distributed big-data processing engine. Pairs with the RAPIDS Spark Accelerator (layer 1) for GPU acceleration. Apache Spark（分散式大數據處理引擎）的 Python 介面；搭配第 1 層的 RAPIDS Spark Accelerator 即可獲得 GPU 加速。

3 · GPU Python Libraries GPU 原生 Python 函式庫

(GPU Python code)
Python libraries written explicitly for the GPU: data stays in GPU memory end-to-end, giving more performance and control — but the code assumes a GPU is present. 明確以 GPU 為前提撰寫的 Python 函式庫：資料自始至終留在 GPU 記憶體中，效能與控制度更高，但程式假設 GPU 存在。
Term 術語Full name 全名Definition (English)說明（繁體中文）
cuDF CUDA DataFrames RAPIDS' GPU DataFrame library with a pandas-like API. Loading, filtering, joining and group-by aggregation all execute in GPU memory. RAPIDS 的 GPU DataFrame 函式庫，API 仿 pandas；讀檔、篩選、合併與分組聚合等操作全部在 GPU 記憶體中完成。
cuML CUDA Machine Learning RAPIDS' GPU machine learning library with a scikit-learn-like API: regression, clustering (e.g., k-means, DBSCAN), dimensionality reduction (PCA, UMAP), random forests and more. RAPIDS 的 GPU 機器學習函式庫，API 仿 scikit-learn：涵蓋迴歸、分群（k-means、DBSCAN）、降維（PCA、UMAP）、隨機森林等演算法。
cuGraph CUDA Graph analytics RAPIDS' GPU graph analytics library — PageRank, community detection, shortest paths and more — and the engine behind the nx-cugraph NetworkX backend. RAPIDS 的 GPU 圖分析函式庫（PageRank、社群偵測、最短路徑等），也是第 1 層 nx-cugraph（NetworkX 後端）背後的運算引擎。
cuVS CUDA Vector Search RAPIDS' library for vector search and clustering on the GPU, providing approximate nearest neighbor (ANN) indexes such as CAGRA and IVF-PQ — the machinery behind GPU-accelerated vector databases and RAG. RAPIDS 的 GPU 向量搜尋與分群函式庫，提供 CAGRA、IVF-PQ 等近似最近鄰（ANN）索引，是 GPU 加速向量資料庫與 RAG 應用的核心元件。
RMM RAPIDS Memory Manager The centralized GPU memory management layer for RAPIDS: memory pools and pluggable allocators that let cuDF, cuML and CuPy share GPU memory efficiently instead of each allocating on its own. RAPIDS 的 GPU 記憶體管理層：提供記憶體池（memory pool）與可替換的配置器（allocator），讓 cuDF、cuML、CuPy 等函式庫高效共用 GPU 記憶體，而非各自配置。
CuPy — (name blends CUDA + NumPy/Python 名稱結合 CUDA 與 NumPy/Python) A NumPy/SciPy-compatible array library for CUDA GPUs. For much code, acceleration is as simple as replacing import numpy as np with import cupy as cp. 與 NumPy／SciPy 高度相容的 GPU 陣列函式庫；許多程式只需把 import numpy as np 改成 import cupy as cp 即可加速。
Numba — (name 名稱) A just-in-time (JIT) compiler for Python: decorators such as @jit compile numeric Python functions to fast machine code at run time, on CPU — and on GPU via its CUDA target (layer 4). Python 的即時（JIT）編譯器：以 @jit 等裝飾器在執行期將數值運算的 Python 函式編譯成高速機器碼；亦可透過其 CUDA 模式編譯 GPU 程式（見第 4 層）。
OpenAI Triton — (name 名稱) An open-source Python-like language and compiler for writing custom high-performance GPU kernels. Heavily used by PyTorch 2's torch.compile. OpenAI 開源的 GPU kernel 撰寫語言與編譯器，以類 Python 語法撰寫高效能自訂 kernel；PyTorch 2 的 torch.compile 大量採用。

4 · Python/CUDA Libraries Python 與 CUDA 混合

(hybrid Python / CUDA code)
Write actual CUDA kernel code from inside Python — Python's convenience with CUDA-level control, for operations no library provides. 在 Python 中直接撰寫或嵌入 CUDA kernel 程式碼——兼顧 Python 的開發效率與 CUDA 層級的控制，適合函式庫未提供的客製化運算。
Term 術語Full name 全名Definition (English)說明（繁體中文）
CuPy RawKernel CuPy raw CUDA kernel interface A CuPy feature for embedding native CUDA C++ kernel source as a Python string; CuPy compiles it at run time and launches it on the GPU. CuPy 的功能之一：將原生 CUDA C++ kernel 原始碼以字串形式寫在 Python 中，由 CuPy 即時編譯並在 GPU 上啟動執行。
Numba CUDA Numba CUDA target (@cuda.jit) Numba's CUDA mode: write CUDA kernels in Python syntax with the @cuda.jit decorator, with direct access to GPU programming concepts such as thread indexing and shared memory. Numba 的 CUDA 模式：以 @cuda.jit 裝飾器用 Python 語法撰寫 CUDA kernel，可直接操作執行緒索引、共享記憶體等 GPU 程式設計概念。
Cython wrappers for CUDA Cython — C-Extensions for Python Cython compiles Python-like code to C/C++, and is commonly used to wrap CUDA C++ libraries so they can be called from Python with minimal overhead. Cython 可將類 Python 語法編譯為 C/C++，常用來「包裝」CUDA C++ 函式庫，讓 Python 能以極低的額外負擔呼叫這些底層功能。

5 · C++/CUDA High Level 高階 C++/CUDA

(high-level C++/CUDA code)
High-level C++ abstractions: compose high-performance GPU programs without writing every kernel from scratch. The RAPIDS libraries themselves are built on this layer. 高階 C++ 抽象層：不必從零撰寫每個 kernel，即可組合出高效能 GPU 程式；RAPIDS 各函式庫的底層即建構於此。
Term 術語Full name 全名Definition (English)說明（繁體中文）
RAFT Reusable Accelerated Functions and Tools A CUDA C++ library of fundamental, widely-used primitives — linear algebra, clustering, nearest-neighbor building blocks — shared as the common foundation under cuML, cuVS and cuGraph. CUDA C++ 的共用基礎演算法庫，提供線性代數、分群、最近鄰等可重用的基礎元件（primitives），是 cuML、cuVS、cuGraph 的共同底層。
CCCL CUDA Core Compute Libraries NVIDIA's umbrella project that unifies Thrust, CUB and libcudacxx (the CUDA C++ standard library) into a single core C++ library suite. NVIDIA 將 Thrust、CUB 與 libcudacxx（CUDA 版 C++ 標準函式庫）整併而成的核心 C++ 函式庫專案。
Thrust — (name 名稱) A C++ parallel algorithms library modeled on the C++ STL — sort, reduce, scan and friends — producing efficient GPU code from high-level calls, no hand-written kernels required. 仿 C++ STL 的平行演算法函式庫（sort、reduce、scan 等），以高階介面直接產生高效率 GPU 程式，不需手寫 kernel。
CUB CUDA UnBound (commonly cited expansion; current docs simply use "CUB" 常見說法，現行官方文件僅稱 CUB) A library of reusable, high-performance primitives at the warp, block and device level — the building blocks used when writing custom CUDA kernels. 提供 warp／block／device 層級的可重用高效能基礎元件，是撰寫自訂 CUDA kernel 時的重要積木。

6 · CUDA Toolkit CUDA 工具組

(C++/CUDA code and kernels)
The foundation: the CUDA compiler, runtime, debugging/profiling tools, and heavily optimized math libraries. Maximum performance ceiling, highest development cost. 最底層：CUDA 編譯器、執行期環境、除錯與效能分析工具，以及高度最佳化的數學函式庫。效能上限最高，開發成本也最高。
Term 術語Full name 全名Definition (English)說明（繁體中文）
CUDA Toolkit CUDA development toolkit The complete development kit for CUDA: the nvcc compiler, CUDA runtime, debuggers (cuda-gdb), profilers (Nsight) and the math libraries listed below. CUDA 的完整開發工具組：包含 nvcc 編譯器、CUDA runtime、除錯器（cuda-gdb）、效能分析工具（Nsight），以及下列數學函式庫。
cuBLAS CUDA Basic Linear Algebra Subprograms The GPU implementation of BLAS: dense linear algebra (matrix multiplication / GEMM and friends). The core numerical engine behind deep learning frameworks. BLAS（基礎線性代數副程式）的 GPU 實作：稠密線性代數運算（矩陣乘法 GEMM 等），是深度學習框架背後的核心數值引擎。
cuDNN CUDA Deep Neural Network library Highly tuned GPU primitives for deep neural networks — convolution, pooling, normalization, attention. PyTorch and TensorFlow rely on it as their GPU backend. 深度神經網路的高度最佳化 GPU 基礎運算庫——卷積、池化、正規化、注意力機制等；PyTorch 與 TensorFlow 的 GPU 後端皆倚賴它。
cuSolver CUDA Solver library GPU-accelerated matrix factorizations and solvers: LU, QR, SVD, eigenvalue problems — the LAPACK-like layer of the toolkit. GPU 加速的矩陣分解與求解器函式庫：LU、QR、SVD、特徵值問題等，相當於工具組中類 LAPACK 的角色。
cuSPARSE CUDA Sparse matrix library GPU-accelerated sparse matrix operations (e.g., sparse matrix–vector multiplication, SpMV), used in graph computation and scientific computing where most matrix entries are zero. GPU 加速的稀疏矩陣運算函式庫（如稀疏矩陣—向量乘法 SpMV）；適用於圖運算與科學計算等大多數矩陣元素為零的場景。
