Fundamentals of Accelerated Data Science

Attendee support guide

Follow these steps before or during the session to set up and launch your hands-on lab environment.

System recommendation

Google Chrome is the preferred browser.

Step-by-step lab setup

  1. Sign in to NVIDIA

    Log in to or create your NVIDIA account.

  2. Join the DLI event

    Open the DLI Event page and enter the event code:

    NCU_RAPIDS_AMBASSADOR_AU26

  3. Find the lab controls

    On the course page, scroll below the slides to locate the Lab Instructions panel.

  4. Initialize the environment

    Select START to begin initializing your interactive environment.

    Please allow up to 10 minutes. Wait until initialization completes.

  5. Wait for LAUNCH

    When initialization is complete, the LAUNCH button becomes active.

  6. Launch JupyterLab

    Select LAUNCH and wait briefly. The interactive JupyterLab environment opens automatically in a new browser tab.

  7. Open the first notebook

    In the left sidebar (File Browser), double-click 1-00_introduction.ipynb. Follow the instructions inside each notebook to proceed through the course exercises.

  8. Expect new output files

    As you run code during the workshop, additional output files—such as .csv, .parquet, and .svg files—will appear naturally in the left file browser.

Course navigation note

The hyperlink in the final cell of 1-07_etl.ipynb is currently not working. After completing that notebook, manually open 1-08_cudf-polars.ipynb by double-clicking it in the left file browser.

Technical support

If you encounter a technical issue with the environment, consult the NVIDIA DLI Platform troubleshooting page.
